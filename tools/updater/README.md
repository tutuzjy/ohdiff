随机修改测试目录，用于构造增量备份测试数据。支持创建和删除文件/目录、追加文件内容，以及文件重命名。程序会直接修改指定目录，请使用测试数据副本。

默认构建不包含此工具。编译方式参考主项目 [README.md](../../README.md#日志实验工具)，配置时通过 `-DBUILD_LOG_TOOLS=ON` 启用。编译后的输出是 `build/<arch>/tools/updater/updater`。

用法：

```bash
updater <目录路径> <变更比例上限> <变更比例下限> [日志路径]
```

* 变更比例以初始文件/目录节点数为基准，单位为百分比；修改计数达到下限后退出，每次操作受上限额度限制。
* 日志路径可选，指定后追加写入二进制操作日志。

例如，在测试目录中生成修改计数占初始节点数约 5%～10% 的变更，并记录日志：

```bash
build/linux/tools/updater/updater /tmp/test-dir 10 5 /tmp/changes.log
```
